# Wallpaper site

Полноэкранный сайт-фон с видео и музыкой.

Запуск:
1. Откройте `index.html` в браузере.
2. Нажмите на страницу или на кнопку "Включить звук", чтобы запустить аудио.
3. При желании можно развернуть браузер на весь экран.

Используемые ресурсы:
- Видео: `gabimaru-hollow-flame.3840x2160.mp4`
- Аудио: `Bôa - Duvet.mp3`

Требования:
- Современный браузер
- Интернет для загрузки медиафайлов

Примечание:
Браузеры могут блокировать автовоспроизведение аудио до первого взаимодействия пользователя с страницей.
